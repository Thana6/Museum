Batticaloa Museum — 3D Interactive Smart Museum
A world-class, fully responsive website for the Batticaloa Museum, Sri Lanka.Combining modern museum architecture, glassmorphism, interactive 3D (Three.js),cinematic animations, AI-powered experience, and multilingual support.

Quick Start
# Install dependencies (for Vercel CLI only)npm install# Local development with Vercel CLInpm run dev# Or simple static servernpx serve .
Deployment
Push to GitHub, then import the repository in Vercel.
No build step required — it deploys as a static site.
